
MIVA MIT PORTFOLIO 4
REDIS KEY-VALUE DATABASE IMPLEMENTATION

Implementation Environment:
- Windows 11
- Memurai Developer Edition
- Redis-compatible command interface
- Port: 6379
- Case Study: Student Management System

1. CONNECTION TEST

Command:
PING

Expected Result:
PONG

2. STUDENT INFORMATION STORAGE

Store student name:
SET student:STU001:name "John Ade"

Retrieve student name:
GET student:STU001:name

Store student status:
SET student:STU001:status "Graduated"

Store department:
SET student:STU001:department "Computer Science"

Retrieve student status:
GET student:STU001:status

Retrieve department:
GET student:STU001:department

3. COURSE CAPACITY MANAGEMENT

Set available course slots:
SET course:CSC401:available_slots 20

Reduce available slots:
DECR course:CSC401:available_slots

Retrieve remaining slots:
GET course:CSC401:available_slots

Expected Result:
19

4. TEMPORARY STUDENT SESSION

Create session:
SET session:STU001 "active"

Set expiration to 300 seconds:
EXPIRE session:STU001 300

Check remaining lifetime:
TTL session:STU001

5. KEY VERIFICATION

List student keys:
KEYS student:STU001:*

Verify course capacity:
GET course:CSC401:available_slots

6. IMPLEMENTATION SUMMARY

The implementation demonstrates:
- Key-value data storage and retrieval.
- Student information management.
- Atomic numeric counter operations.
- Automatic key expiration.
- Time-to-live verification.
- Key inspection and verification.

7. SUITABILITY

The Redis key-value model is suitable for:
- Temporary student login sessions.
- Fast access to student profile information.
- Course registration capacity counters.
- Frequently accessed application data.

Note:
Memurai Developer Edition was used as a
Redis-compatible implementation on Windows 11.
